## 📝 代码结构与模块说明

业务逻辑分别位于 `logic_zh/` 和 `logic_en/`，由中文和英文界面调用。各模块围绕图像目录和中间结果衔接，既可通过 GUI 连续运行，也可在已有前序结果的基础上选择部分步骤。

### `image_classifier.py`：图像分类与整理

该模块递归读取源目录，根据文件名中的通道后缀区分明场与荧光，将两类图像分别复制到 `bri` 和 `flu`。整理时保留样本子目录及原文件名，使后续模块能够按视野配对。这里的分类是通道整理，不涉及模型判断。

### `light_balance.py`：明场光场平衡

该模块先将明场灰度范围归一化，再通过高斯平滑估计局部光照分布，按局部亮度进行补偿。随后采用伽马校正与 CLAHE 增强微坑和磁珠的对比度，将处理结果以 `_sol.tif` 后缀保存到 `bri_sol`。其输出同时供微坑检测、训练集打标和含珠预测使用。

### `microwell_detection.py`：微坑检测与 mask 生成

该模块读取校正明场，经过对比度增强与平滑后，使用 Hough 圆变换检测微坑中心。程序在各中心位置绘制固定半径的圆形区域，生成包含全部候选微坑的二值 mask，保存到 `bri_mask`。这一步确定后续需要逐个判断的微坑位置。

### `manual_labeling.py`：训练集打标

该模块根据明场图像和微坑 mask 提取单坑区域，并为操作者选中的中心微坑生成 3×3 邻域预览。操作者结合中心坑与周围参考坑的外观，标记“空坑”或“含珠坑”。程序保存拼接图像，以及记录标签、中心坐标和图像路径的 CSV，为监督训练提供样本。

### `train_model.py`：Swin-Transformer 模型训练

该模块读取标签 CSV 及对应邻域图像，划分训练集与验证集，并完成缩放、径向亮度加权、三通道转换和归一化。随后加载预训练的 Swin-Tiny，使用带中心坑标签的样本进行二分类微调。训练过程中记录损失和验证准确率，并根据改善情况保存模型参数，供批量预测调用。

### `bead_prediction.py`：含磁珠微坑预测

该模块从校正明场及全部微坑 mask 中提取候选单元，为每个中心坑构建 3×3 邻域图像，再分批输入训练好的 Swin-Tiny。对于含珠概率大于 0.5 的单元，程序保留对应中心坑的区域，合成为 `_bead.tif` 有效 mask。邻居查询缓存、归一化查表和图块预取用于提高批处理效率。

### `fluorescence_analysis.py`：荧光信号与 AMB 分析

该模块将含珠 mask 与同一视野的荧光图像配对，计算各有效微坑的平均荧光强度，确定阳性阈值并绘制散点图。在得到阳性数和有效单元数后，计算逐图 AMB，并按样本目录合并结果、筛查高值离群图像。最终导出逐图明细、筛除前后的汇总和独立剔除清单。

### 启动与界面

`launcher.py` 提供语言选择入口，`main_gui_zh.py` 和 `main_gui_en.py` 分别提供中文与英文界面。界面负责接收文件路径、模型和任务选项，依次调用各逻辑模块，并显示处理进度、结果和错误。各逻辑目录中的 `__init__.py` 用于声明 Python 包。
